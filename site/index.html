FAQ

Questions

Is it really free?

Yes. There is no subscription, no Pro plan and no credits — one version, with everything in it. The code is open source under the MIT licence.

Do I need an API key for the AI?

No. Fillsmith uses Gemini Nano, the model built into Chrome, which runs on your machine. It needs Chrome 138 or later and a one-time download by Chrome of about 2 GB on supported hardware. Without it, the rules still fill every field they recognise. You can add your own Anthropic, OpenAI or Gemini key if you prefer a hosted model.

What does it send, and where?

By default, nothing — the rules and the built-in model run in your browser. Only if you add your own API key does anything go out: for fields no rule could answer, their labels, limits and options, the form's title and a few short texts from a table on the page, to the provider you chose. There is no analytics and no telemetry. Read the privacy policy.

Will it work on my app?

On any page you can open in Chrome: localhost, staging, production. It drives native controls and the widgets of the common component libraries, and falls back to ARIA for the rest. If a field comes out wrong, report it — each fix ships with a test.

Can I get the same data twice?

Yes. Pin a seed in Settings and every fill produces the same person — what you want when you are reproducing a bug rather than finding one.
